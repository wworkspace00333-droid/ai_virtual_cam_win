# Проверка на реальном железе (Windows 10 / 11)

Разработка и все тесты шли на виртуальном сервере: Windows Server 2025, 2 ядра, **без видеокарты** (Direct3D через
программный WARP), вход по RDP. Ниже — всё, что там проверить было нельзя. Цифр для этих пунктов в документации нет
намеренно: их нельзя выдумывать, их нужно измерить. Отметьте пункт, запишите результат и версию программы.

Что уже проверено на сервере, перечислено в [AUDIT_WIN.md](AUDIT_WIN.md), раздел 8, и в CHANGELOG.

## 0. Подготовка

- [ ] Компьютер: модель процессора, объём памяти, видеокарта и версия драйвера, Windows 10 или 11 и номер сборки
      (`winver`).
- [ ] Поставить программу из релиза. Сначала сверить SHA-256 установщика с файлом `.sha256` в релизе:
      `Get-FileHash .\AIVirtualCameraStudio-Setup-0.4.4.exe -Algorithm SHA256`.
- [ ] Отчёт о производительности (железо, скорость ИИ на каждом бэкенде, конвейер в каждом режиме, режимы камеры):
      `"C:\Program Files\AI Virtual Camera Studio\vcstudio.exe" --run-script windows_pc_report.py --out "%USERPROFILE%\Desktop\pc-report"`
      Папку `pc-report` (`report.md`, `report.json`) приложить к результатам.

## Как вернуть результаты

Заполненный файл (или копию этой страницы) и папку `pc-report` — в issue репозитория или напрямую разработчику.
Номер версии программы — в заголовке её окна.

      but the model ran on CPU") and be faster than the CPU line.

      extra camera: placeholder or held frame, main output keeps its rate; plug back: the tile returns.

      lip sync in the MP4.
- [ ] Remote Control from a phone on the same Wi-Fi (LAN opt-in): scene buttons, recording, privacy; Windows Firewall
      prompt appears once and can be declined to keep it local only.
