## 4. Что вообще не покрыто тестами на Windows

- Реальная видеокарта: DirectML, D3D11 на GPU, GPU-слои фона, нехватка VRAM (D1).
- Физические веб-камеры (MF и DirectShow) — тесты используют виртуальные устройства.
- Клиенты камеры: Zoom, Teams, Discord, браузеры, «Камера» Windows.
- Установленная программа: кроме `--self-check`, ни один инструмент `--run-script` не запускается в CI (D9).
- Полный диск и папка кэша без прав на запись (D22, D23).
- Автозапуск после реальной перезагрузки.
- Сценарии GUI с детектором (4 теста ждут macOS-модель).
- Модели «любых предметов» из установщика: их нет в CI (скачиваются по кнопке), тесты открытой лексики пропускают
  живую часть без моделей.
