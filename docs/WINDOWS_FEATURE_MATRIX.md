# Windows-версия: матрица функций (аудит 0.4.1, 2026-11-16)

Статусы: **READY** — реализовано, подключено к приложению и подтверждено тестами или живой проверкой;
**PARTIAL** — работает частично или с важными ограничениями; **BROKEN** — есть, но не работает;
**MISSING** — нет; **UNVERIFIED** — код есть, но на этой машине подтвердить нельзя (нет видеокарты, нет программы);
**BLOCKED** — заблокировано внешним требованием (сертификат, SDK, политика среды).

Машина аудита: Windows Server 2025, 2 ядра Xeon, 31 ГБ, без видеокарты (Microsoft Basic Render Driver, WARP),
вход по RDP. Сборка: ветка `windows-port` = `win/main` @ `bd3c8c1`, установлена программа 0.4.1.
Колонки: Код / Подключено к приложению / GUI / В конвейере / Ошибки обрабатываются / Тесты (проходят) / Статус.
