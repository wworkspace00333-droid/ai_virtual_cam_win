# Windows-версия: план 0.4.1 → 0.5 (предложение, ждёт утверждения)

Основан на `WINDOWS_AUDIT_0.5.md`, `WINDOWS_FEATURE_MATRIX.md`, `WINDOWS_TECHNICAL_DEBT.md`. Ход работ — в разделе
«Статус» в конце. Сложность: **S** — до дня, **M** — 2–4 дня, **L** — 1–2 недели, **XL** — больше (оценки для одного
разработчика с ассистентом; без учёта ожидания сертификата и железа).

Архитектура для новых функций — нативная Windows (Media Foundation, Direct3D 11, ONNX Runtime/DirectML), а не копия
macOS: в macOS-репозитории этих функций нет (он на 0.3.2).

## Рекомендуемый порядок

1. **P0.1** (замер на реальном ПК) — без него всё, что связано с GPU, планируется вслепую.
2. **P0.2–P0.6** — короткие исправления найденных сегодня дефектов (вместе ~2–3 дня).
3. **P0.7** — подпись: запустить покупку/оформление сертификата параллельно.
4. **P1.1, P1.8, P1.6, P1.7** — быстрые улучшения ядра; затем **P1.2** (сегментация) и **P1.3–P1.5** по итогам P0.1.
5. **P2.1 Планировщик** → **P2.2 Сцены** (на них опираются остальные) → **P2.3, P2.4** → **P2.5, P2.6** → **P2.7, P2.8**.
6. **P3.1 → P3.2 → P3.3**, затем P3.4–P3.7 и выпуск 0.5.
